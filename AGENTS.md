# Project Instructions

## Project

This is a Java backend project with a DevOps-oriented workflow.

## Technology

- Java 21
- Spring Boot
- Maven
- MySQL
- Docker
- GitHub Actions

## Architecture

Use:
Controller → Service → Repository → Model

## Coding Rules

- Use clean and readable Java.
- Follow OOP principles.
- Keep business logic inside Service.
- Do not put business logic inside Controller.
- Use meaningful class and variable names.
- Write tests for important services.
- Do not add unnecessary dependencies.

## DevOps Rules

- Application must be buildable with Maven.
- Application must be runnable inside Docker.
- CI should run tests before building the application.

## AI Agent Rules

- Before changing code, inspect the existing project structure.
- Do not rewrite working code unnecessarily.
- Explain significant changes.
- Ask before making destructive changes.
